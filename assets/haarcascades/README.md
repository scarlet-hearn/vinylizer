# OpenCV cascade models

Unmodified model files from the OpenCV **4.10.0** release:

- [haarcascade_frontalface_default.xml](https://github.com/opencv/opencv/blob/4.10.0/data/haarcascades/haarcascade_frontalface_default.xml)
- [haarcascade_eye.xml](https://github.com/opencv/opencv/blob/4.10.0/data/haarcascades/haarcascade_eye.xml)
- [haarcascade_smile.xml](https://github.com/opencv/opencv/blob/4.10.0/data/haarcascades/haarcascade_smile.xml)

Each XML retains its upstream copyright and license notice. Distribute these files,
including their notices, alongside the application. The smile cascade refines the
mouth region when it finds a smile; it is not a general mouth or landmark detector.
